# Expression:

An expression is code that evaluates to an value. e.g. 5 would produve 5, let foo =+ bar would become foobar

# Statement

An statement is an instruction to performan an action e.g. a (for in) loop

# Implicit return

(x) => x\*2 immedeiatly returns the value

# Return with a function body

(x) => {x\*2}. This executes the expression but does not return anything
